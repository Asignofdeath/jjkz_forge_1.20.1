## ⛔ 铁律：CMDCam 运镜期间 `hideGui=true` ⇒ `RenderGuiEvent` 整段不触发

**症状**：1.3「醒来眨眼」（`QuestWakeBlinkOverlay`）**完全看不到**。触发链路（服务端包 → `SyncQuestWakeBlinkS2CPacket.play()` → `QuestWakeBlinkOverlay.play()`）全对，`active=true` 也设了，就是不显示。

**根因**：该层原本画在 `RenderGuiEvent.Post`。而它与**背影镜 CMDCam 同拍启动**（`MainQuest13Performance.tickBlackoutHold` 里 `MainQuest13CmdCamS2CPacket.backView` → 紧接着 `SyncQuestWakeBlinkS2CPacket.play()`），CMDCam 运镜会把 `options.hideGui` 置 true ⇒ `GameRenderer` 跳过 `Gui.render` ⇒ Forge 的 `RenderGuiEvent` **根本不派发** ⇒ 眼皮一帧都没画。
- 已用 `javap` 扫 `cmdcam-251244-6099081` jar 求证：`hideGui` 出现在 `team/creative/cmdcam/client/CMDCamClient` 与 `.../common/scene/run/CamRun`。

**规避范式（照抄 `QuestCinematicLetterboxOverlay`）**：需要「无论 hideGui 与否都要画」的整屏效果，一律走 **`TickEvent.RenderTickEvent` END + 自建 `GuiGraphics`**：
```java
if (event.phase != TickEvent.Phase.END || !active) return;
Minecraft mc = Minecraft.getInstance();
int w = mc.getWindow().getGuiScaledWidth(), h = mc.getWindow().getGuiScaledHeight();
RenderSystem.backupProjectionMatrix();
RenderSystem.setProjectionMatrix(new Matrix4f().setOrtho(0, w, h, 0, 1000, 3000), VertexSorting.ORTHOGRAPHIC_Z);
PoseStack mv = RenderSystem.getModelViewStack(); mv.pushPose(); mv.setIdentity();
mv.translate(0, 0, 1000 - 3000); RenderSystem.applyModelViewMatrix();
GuiGraphics g = new GuiGraphics(mc, mc.renderBuffers().bufferSource());
g.fill(...); g.flush();
mv.popPose(); RenderSystem.applyModelViewMatrix(); RenderSystem.restoreProjectionMatrix();
```
⛔ 别再在 `RenderGuiEvent` 上挂「演出开场/运镜期间」的整屏遮罩——1.3 的红黑幕之所以没事，只因它在 **CMDCam 起播之前**（阶段 1/2）。

**改动**：`client/QuestWakeBlinkOverlay` 换绘制钩子（`onRenderGui`→`onRenderTick`）+ 自建 `GuiGraphics`/正交投影；删 `DRAW_Z`；import 换成 `TickEvent/PoseStack/VertexSorting/Matrix4f`。逻辑（`lidClose` 曲线、`COD_BAND=96` 底栏留白）一字未改。
- ⚠️ 连带事实：`QuestCodCaptionOverlay.onRenderGui`（眨眼期间在最上层重画 COD）现为**死代码**——那 4 秒里 `RenderGuiEvent` 不派发。但 COD 正片走 `RenderTickEvent`，且眨眼 4 秒内根本没有对白（对白在 `WAKE_BLINK` 结束后才开始），故不影响，未动。

## 主线 1.2：鬼打墙（`MainQuest12LoopTrap`）改固定编排

- 顺带删掉由改动造成的死代码：`horizontalMoveSinceLastSample()` + `TrapState.lastSampleX/lastSampleZ/hasLastSample/lastTriggerExploreTick`。
- 折返与台词逻辑（`tryRewind` / `playLoopLine` / `LOOP_KEYS`）一字未动。
