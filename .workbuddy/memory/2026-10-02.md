## 阶段 4：扫描波（路线 B 落地，完成）

用户指了参考实现：隔壁 JoJo 模组 `C:\D\MineMOD\jcraft-eoe-arch-1.20.1` 的时停特效就是想要的扫描波，让照着看。

### JCraft 时停（`za_warudo`）怎么做的
- 本体是 **PostChain 后处理** + **深度缓冲反投影**：`za_warudo.fsh` 用 `DepthSampler` + `calcEyeFromWindow` 把每个像素的深度还原成**世界坐标** → `distance(pixelPos, Center)` → 四组 `smoothstep` 相乘造**双线亮环**（主环 @ `Radius` ±1 格、次级环 @ `Radius-2`）→ `pow(..., 3.0)` 白色自发光；另外球内做色相补色 + 鱼眼折射、球外 `OuterSat` 变灰。
- 动画：半径按世界格，扩张 4/tick × 25t → 反转点 → 收缩 8/tick × 25t，峰值 100、总 50 tick；`lerp` 相邻 tick 消除台阶。
- 基建：自封 `PostEffect`/`PostProcessor`；`RenderTarget` Mixin（`StillDepthHolder`）暴露深度纹理；注入点在 `LevelRenderer.renderLevel` 的 transparencyChain 之后；`ShaderActivationPacket` 只发给球心 96 格 AABB 内玩家。

### 三条路线与取舍（用户批准 C）
- **A**：完整复刻 PostChain + Mixin 取深度 ⇒ 折射 / 补色 / 地形遮挡全都有。质量最高，但要新搭一整套后处理设施 + 一个 Mixin。
- **B**：纯 **core shader** 全屏正交 quad，靠 `InvViewProj` 反投影逐像素算视线，解析求环带。**拿不到深度、读不到主帧缓冲**，代价是：① 环**穿墙**（无遮挡）② 无折射 / 补色。
- **C**（采纳）：**先 B 定手感**，之后再决定是否升级 A。

### ⛔ 硬限制（本项目 shader 管线）
`RegisterShadersEvent` + `ShaderInstance` 的 core shader 结构上**读不到主帧缓冲、也拿不到深度纹理** ⇒ 折射与补色在此路线下物理上做不了，环也不可能被地形遮挡。想要就得上路线 A。

### 取值与坑
- **半径曲线**（客户端）：三角波 `0 → 64 → 0`（`MID_PROGRESS = 0.5`），总 50 tick = t=20 → t=70，**波收完正好成型**。

## 阶段 4 增料：用户反馈「效果太素」→ 多层波阵面（完成）

实机看到「白环展开又收束」，但太素（只有一条理想圆的细白线）。

**⛔ core shader 的能力边界（决定了能加什么）**：拿不到深度 ⇒ 不知道每个像素沿视线命中的世界点 ⇒ 球内雾 / 折射 / 补色 / 地形遮挡**全都做不了**。可用信息只有：屏幕 UV、视线方向（世界）、相机位置、球心与半径。
- **地面分支例外**：视线与球心水平面求交可拿到**真实世界交点**，所以地面上的花样可以做得很多。
- **球壳只能做屏幕空间投影圆**的装饰。

增料内容（`domain_scan_wave.fsh` 重写 + json 加 `Time` + renderer 传秒数）：
1. `ringProfile(delta, width)` 取代原 `ringBand`：**锐核 + 4.5 倍宽的柔晕**（×0.32），不再是硬方波带。
2. **多层回波**：主波前 + 内侧拖 3 环 + 外侧带 2 环，宽度递增 / 亮度递减 ⇒ 有厚度的波阵面。
3. **贴前柔光**：`smoothstep(band*10, 0, |distW - Radius|) * 0.16`，让环像在发光。
4. **同心「无限」细环**：每 8 格一圈（`fract(dist/8)` 取两侧最近线），×0.10，越靠外越淡 ⇒ 无限回廊感。
5. **放射条纹**：`pow(|sin(ang*9 + Time*0.9)|, 10)` ×0.20，随缓慢旋转。
6. **球壳**：主环 + 内外各一圈细环 + 球盘内部柔光（让「球」不只是「环」可见）。
7. **波前噪声扰动**：两频 `valueNoise(ang*…)` 叠加乘 `band*1.4`，破坏完美圆形。
8. **时间脉动** `0.86 + 0.14*sin(Time*20)` + **软饱和** `1-exp(-x*1.8)`（多层叠加不爆白）。
