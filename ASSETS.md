### 4. Official Audio Removed

Out of respect for rights holders, the following audio was previously bundled with the mod and has now been **entirely removed — it is no longer distributed with the mod**.

- **Domain "perfect" BGM**: `domain.limitless_domain_perfect`, `domain.shrine_perfect`, `domain.chubukushishi_perfect` (plus the unused legacy file `domain.chubukushishi_perfect.ogg`)
- **Sukuna mimicry voices**: `character.sukuna.hmph`, `character.sukuna.kai`, `character.sukuna.fuga`, `character.sukuna.zongai_tanoshimeta`

The corresponding **sound-event IDs and playback logic are retained** as a resource-pack interface; the mod itself no longer ships these files. All sounds in this mod use the standard resource path `assets/jujutsukaisenzone/sounds/**` and follow Minecraft's resource-pack override mechanism, so any resource pack may override mod sounds with its own same-named `.ogg`. Any audio supplied by users through their own resource packs is the user's sole responsibility — the mod author is not responsible for its content or licensing.
